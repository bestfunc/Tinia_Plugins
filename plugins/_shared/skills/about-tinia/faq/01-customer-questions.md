# 客户高频问题 FAQ

> 客户接触 Tinia 时最常问的 20+ 问题 + 标准回答。给销售 / 客户成功 / 售前现场用，AI 也可以直接读。

---

## 产品定位

### Q：Tinia 跟 HEAD ArtemiS / Siemens Testlab 比有什么不一样？

**A**：三句话回答：

1. **架构**：我们是云原生 + 节点 DAG + AI-native；他们是 30 年 C++ 桌面单机软件
2. **更新方式**：我们有节点商店即时更新；他们年度大版本
3. **AI 协作**：我们 MCP-native，Claude Code 能直接驱动；他们没有 AI 工程师助手形态

详见 `../reference/06-competitive-landscape.md`。

### Q：你们能做 EMA / TPA / Beamforming 吗？

**A**：诚实回答：

- EMA / TPA：H2 不做，2027 Q1 评估
- Beamforming：需要硬件配合，不在我们核心范围
- 建议：如果是您主要业务，HEAD/Testlab 更合适；如果是 NVH 工程的 5-10% 偶尔用，找朋友单位临时用 HEAD

不要假装能做。客户感受到诚实比"什么都行"更信任。

### Q：你们有多少个算法？比 HEAD 少很多吧？

**A**：

> 短期是少。HEAD 30 年累积 134 项笛卡尔积算法清单，我们目前 33+ 节点。
>
> **但**：
> - 我们覆盖核心高频算法（您日常用到的 10-20 个，我们都有）
> - **AI 编排让有限节点能搭出无限组合** —— 比单纯堆数字更有价值
> - 节点商店让算法不靠我们一家供给，全行业开发者贡献
>
> 我们计算过：30 项节点 + AI 编排，能覆盖 NVH 工程师 80%+ 日常工作。剩下的 20% 真需要 HEAD 的可以并行用。

### Q：Tinia 是不是只做汽车 NVH？

**A**：当前主要客户是 NVH 工程师，但定位更广 —— **工业声学 / 振动 / NVH** 整个领域：

- 汽车 NVH（主力）
- 风电 PdM
- 工业泵 / 电机
- 家电声学
- 高校研究

未来 Production 阶段会扩展到更多场景。

## 部署 / 数据安全

### Q：数据安全怎么保证？

**A**：三种部署方式按客户偏好选：

| 部署 | 数据位置 | 适合 |
|---|---|---|
| SaaS | 我们托管的服务器 | 数据可上云、个人 / 小团队 |
| 私有化（Server）| 客户内网 | 数据敏感、内网部署 |
| 桌面单机（Desktop）| 客户本机 | 极致合规、单工程师场景 |

详见 `../reference/10-deployment-modes.md`。

### Q：你们的代码是开源的吗？

**A**：分层开源：

- **核心 engine**（tinia-engine）：规划开源（Apache-2.0）—— 让生态可信
- **业务层**（多租户、商店、AI MCP）：保留闭源 —— 这是商业模式核心
- **节点 SDK**（tinia_runtime）：开源（节点开发者必须能看）

未来 5 年公司即使停摆，社区也能基于开源 engine 继续。

### Q：私有化部署需要我们 IT 干啥？

**A**：

- 准备 Linux 服务器（一台 16 核 32G 起步够小团队用）
- PostgreSQL + MinIO（用 docker-compose 一键启）
- 我们提供完整部署文档 + 远程协助 1-2 天可完成
- 后续升级也是远程操作

### Q：能上 OpenStack / 阿里云 / 华为云私有云吗？

**A**：能。Tinia 是标准 Linux 应用，只要环境支持 Docker / K8s 即可。我们用过的客户云包括 OpenStack、阿里云专有云、华为云 Stack。

## 商业 / 定价

### Q：怎么收费？

**A**：三层产品分别：

- **Community**（免费）：基础节点 + 单通道分析
- **Pro**（按 seat）：订阅 / 永久买断双模式
- **Production**（项目制）：含咨询、集成、培训

具体价格按客户规模、采购周期、定制需求由销售报。

### Q：Pro 试用怎么申请？

**A**：

- 联系销售：申请 3 个 seat × 3 个月免费试用
- 无信用卡 / 无续费陷阱
- 试用到期自动降级 Community（数据保留，仅锁 Pro 节点）

### Q：买断 vs 订阅哪个划算？

**A**：分情况：

- **创业公司 / 自由职业者**：订阅，灵活，现金流好
- **国企 / 大企业**：永久买断，一次性预算审批
- **不确定能用多久**：先订阅 1 年验证，确认好用后转买断
- **预算紧张但要长期用**：买断 + 维护费

### Q：发票能开吗？

**A**：能。支持增值税专票（境内）+ Invoice PDF（境外）。开票按合同条款，由销售 / 财务对接。

### Q：教育许可有折扣吗？

**A**：有。学生 / 教师 / 高校实验室申请教育许可：

- 师生个人：Pro 半价或免费
- 实验室 / 课题组：折扣后团队版

申请方式：销售对接，提供学校证明。

## 学习 / 上手

### Q：学习成本高吗？

**A**：分场景：

- **HEAD 老用户**：1-2 周熟悉新工作流（节点 DAG vs 菜单驱动）
- **新人 NVH 工程师**：2-4 周从零上手（AI 助手降低门槛大）
- **学生**：1-2 天能跑通基础流程，1-2 周能写自己的节点

跟传统工具相比，Tinia 学习曲线**更陡但更短** —— 因为概念集中（DAG + 节点），不像 HEAD 几百个菜单。

### Q：有教程吗？

**A**：

- 文档站：完整文档 + 视频教程（B 站 + YouTube）
- AI 助手：装 Claude Code + Tinia plugin 就能问 AI"怎么做 XX"
- 客户成功：Pro 用户每周可预约 1 次远程指导

### Q：能跟 HEAD 共存吗？

**A**：完全能。Tinia 不修改您的 HEAD 安装，数据格式也兼容（wav / mat 等通用格式）。

建议：用 Tinia 跑日常 80% 工作，HEAD 留给 EMA / TPA / Beamforming 等深功能。

## 节点 / 商店

### Q：你们的节点是谁开发的？

**A**：当前几乎全部是 Bestfunc 自研（`bestfunc/*` namespace）。

未来（2027）节点商店对外开放后，外部开发者（高校研究者 / 独立顾问 / 公司团队）也能发布。

### Q：节点质量怎么保证？

**A**：三层保障：

1. **商店审批**：算法正确性 + 性能 + 安全
2. **用户评分**：差节点自然淘汰
3. **官方认证**：标记"Bestfunc Certified"的节点是我们额外验证过的

### Q：我们想发自家算法节点怎么发？

**A**：两种范围：

- **公开发布**：所有 Tinia 用户可见可装，商店审批
- **私有组织池**：仅你们公司内部可见，无需外部审批

发布流程详见 `../reference/12-node-ecosystem.md`。

### Q：商业节点 30% 平台分成怎么计算？

**A**：跟 Apple App Store / Steam 同样模型：

- 用户支付 → 商店收 30% → 开发者拿 70%
- 月度结算到开发者账户
- 跨币种自动转换

### Q：节点会不会过气没人维护？

**A**：商店有"活跃度"指标：

- 作者多久更新一次
- 用户最近一次安装时间
- 长期无人维护的节点会被标记 → 推荐替代

公司用户可付费"托管节点维护"，让 Bestfunc 接管。

## AI 协作

### Q：AI 是基于 ChatGPT 还是 Claude？

**A**：**Tinia 不绑定任何特定 LLM**。Tinia 暴露的是 MCP（Model Context Protocol，Anthropic 主导的开放协议）接口。

支持的 AI 客户端：

- **Claude Code**（Anthropic 官方）—— 当前主推
- **Codex**（OpenAI Codex CLI）
- **Qwen CLI**（阿里）
- 其他 MCP-compatible 客户端

您选哪个 LLM 都行。Tinia 这一侧不变。

### Q：AI 会泄露我们的数据吗？

**A**：

- AI 客户端跑在您自己的电脑 / 公司机器上，**不是云端服务**
- AI 调用 Tinia 工具时，数据流向：客户端 ↔ Tinia（您的部署）↔ LLM provider
- 客户端 → LLM provider 的数据由您选的 LLM 决定（Claude API / OpenAI API / 本地 LLM）
- 私有化部署 Tinia + 本地 LLM = 数据 0 出域

### Q：AI 写的代码靠谱吗？

**A**：跟普通 AI 写代码一样：

- 简单 / 常规算法（FFT / 滤波）质量高
- 复杂 / 创新算法需要工程师 review
- 跟工具栈 / SDK 紧密相关的代码（用 Tinia SDK）AI 因为有完整文档质量很好

建议：**AI 写 + 工程师审**，是当前最佳实践。

### Q：我们不想用 AI，能用 Tinia 吗？

**A**：完全能。Tinia 的所有功能都有 UI 操作 + REST API。AI 是**可选的工作方式**，不是必需。

不用 AI 也能享受：节点 DAG 流程编辑、节点商店、看板、团队协作等全部功能。

## 长期 / 战略

### Q：5 年后你们还在吗？

**A**：三层保障：

1. **流程 JSON 开放**：您的流程定义是标准化 JSON，无论 Tinia 在不在都能解析
2. **节点代码可控**：商业节点签合同保留源码托管；自研节点完全在您手里
3. **核心 engine Apache-2.0 开源**：公司停摆社区也能继续

我们认为最大的护城河不是 lock-in，是产品好让您不想走。

### Q：能跟 HEAD / Testlab 数据互通吗？

**A**：当前通过通用格式互通：

- wav / mat / unv / hdf5 等通用文件格式
- 大部分指标导出为 CSV / JSON / Parquet
- 不能直接读 HEAD .ats 内部格式（专有格式）

未来视客户需求，可能开发 .ats / .lda 等格式的导入节点。

### Q：你们融资了吗？团队多大？

**A**：

> Tinia 由 Bestfunc 推进。Bestfunc 是一家有多年工业声学 / 振动 / NVH 与 AI 经验的团队，已有现有声学相关产品业务（SmartQuality 在线检测平台、Argus 工业 AI 运维平台）。Tinia 是新一代核心产品。
>
> 具体团队规模、融资情况、财务状态等信息我们不便对外披露，需要时通过销售 / BD 渠道获取。

## 售后 / 服务

### Q：客户支持有 SLA 吗？

**A**：

- **Community**：社区支持（GitHub Discussions、文档）
- **Pro**：邮件 + Discord + 工单（典型响应 24h 内）
- **Pro 团队版**：包含基础 SLA
- **Production / 企业**：定制 SLA（含 4h 响应、专属客户成功等）

### Q：能定制开发吗？

**A**：能。三种形态：

- **定制节点**：客户提需求，我们做节点（客户独占或上架商店）
- **集成咨询**：跟客户现有系统（MES / ERP / Diffgram）集成
- **私有化部署 + 培训**：现场部署 + 团队培训

定价按工时 / 项目报，由 BD 商谈。

### Q：培训怎么安排？

**A**：

- **远程培训**：1-2 天，免费给 Pro 团队版客户
- **现场培训**：1-3 天，按差旅 + 工时报价
- **视频教程**：B 站 + YouTube 公开
- **企业认证课程**：规划中
