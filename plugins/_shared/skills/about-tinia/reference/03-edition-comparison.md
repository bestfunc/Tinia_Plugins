# 三层产品矩阵对比

> 一张表看清 Community / Pro / Production 三层的功能差异、目标用户、定价模式。给客户做评估时直接引用此页。

---

## 速览对比

| 维度 | Community | Pro | Production |
|---|---|---|---|
| **代际定位** | 入门 + 生态层 | 主交付层（2026 H2）| 在线产线层（2027 规划）|
| **目标用户** | 学生 / 研究者 / 个人工程师 | NVH 工程师 / 研究院 / Tier1 测试部门 | 工厂在线监测（风电、工业泵、电机厂等）|
| **部署形态** | 桌面单机 | 桌面单机 / 云端 SaaS | 多机协同（边缘 + 云端）|
| **节点访问** | 基础节点 + 商店免费节点 | 全部节点 + 商店付费节点 | Pro 全部 + 实时流处理节点 |
| **流程复杂度** | 限定（节点数 / 通道数）| 不限 | 不限 + 多机分布式 |
| **AI 辅助** | ✅ MCP | ✅ MCP + 高级 AI 编排 | ✅ MCP + AI 异常诊断 |
| **多通道** | 单通道 | 多通道（per_channel / aggregated）| 多机多通道协同 |
| **报告导出** | ❌ | ✅ PDF / Word / PPT + 4 模板 | ✅ + 自动定时报告 |
| **Order Tracking** | ❌ | ✅ | ✅ |
| **看板（Dashboard）** | 基础 | 完整 | 完整 + 实时刷新 |
| **数据库 / MES 集成** | ❌ | ❌ | ✅ |
| **告警 / 异常推送** | ❌ | ❌ | ✅ |
| **模型 OTA / 流程热更新** | ❌ | 节点商店即时更新 | ✅ 跨机器全局 |
| **协作** | 单用户 | 团队共享 + 流程复用 | 工厂级共享 |
| **定价** | 免费（商业节点单独收费）| 按 seat 订阅 / 永久买断 | 按项目（含咨询服务）|
| **支持** | 社区（GitHub Discussions）| 邮件 + Discord + 工单 | 专属技术支持 + SLA |

## Community —— 反向培养生态

### 目标用户

- **学生**：本科 / 研究生 / 博士，做声学相关课题
- **研究者**：高校老师、研究院青年研究员
- **个人工程师**：业余研究、Side project、开源贡献者

### 提供什么

| 模块 | Community 提供 |
|---|---|
| 安装 | 桌面单机版，Windows / macOS 直接下载 |
| 基础节点 | 声级表 / FFT / 频谱 / 滤波 / 时域统计等核心算法 |
| 数据源 | 本地文件（wav / mat / unv 等）+ 内置信号发生器 |
| AI 编排 | 完整 MCP 接入，可用 Claude Code / Codex / Qwen CLI 驱动 |
| 节点开发 | 完整 DevStudio + CLI，能写新节点（自用 + 发布到商店）|
| 商店 | 浏览 / 安装免费节点；商业节点单独购买 |

### 限制（保留 Pro 价值）

| 维度 | Community 限制 |
|---|---|
| 流程复杂度 | 单流程节点数 ≤ 20 |
| 通道 | 单通道分析（多通道节点跑会提示升级 Pro）|
| 报告导出 | 仅截图 + JSON / CSV，不含 PDF / Word / PPT 模板 |
| Order Tracking | 不可用 |
| 团队协作 | 单用户，不能共享流程到组织内 |

### 为什么免费

- **建立生态**：研究者发布算法到商店 → Pro 用户订阅 → 形成正反馈
- **反向培养未来 Pro 用户**：今天的学生是 3 年后的 NVH 工程师
- **传统对手不敢做**：HEAD / Testlab 核心客户是大企业，免费版会侵蚀付费版；Tinia 起步没存量包袱

### 升级路径

Community 用户用一段时间后碰到限制（节点数 / 通道 / 报告需求），UI 直接弹"升级 Pro 试用 3 个月"。Pro 试用到期自动降回 Community（保留全部数据 / 流程，仅锁定 Pro 节点）。

## Pro —— 主交付层（2026 H2）

### 目标用户

- **整车厂 NVH 工程师**：日常做发动机声品质、风噪、底盘振动等分析
- **研究院 / 检测中心**：第三方测试服务，需要标准化报告
- **Tier1 供应商测试部门**：给主机厂出报告，复用流程降本

### 提供什么（Pro 独占）

| 能力 | 说明 |
|---|---|
| **完整节点库** | 全部官方节点 + 节点商店付费节点（订阅 Pro 后可访问）|
| **多通道分析** | 麦克风阵列、多传感器同步分析；通道命名模板、Composite DataSource |
| **Order Tracking** | RPM 通道 + 角度域重采样 + Campbell / Order Spectrum / Order Tracker |
| **物理量 + 单位系统** | Pa / g / m/s 全链路贯通，calibration 链路完整 |
| **报告导出** | PDF / Word / PPT，4 个内置模板，可定制 |
| **多运行 overlay** | 多次实验结果叠图对比 |
| **完整 PSD / Welch / 时域统计** | RMS / Crest / Kurtosis 套件 |
| **团队共享** | 组织内流程模板 / 数据源 / 凭据共享 |
| **看板（Dashboard）** | 多 Viewer 组合 + 切片器（slicer）+ 文本块布局 |
| **AI 高级编排** | "帮我分析这段录音的声品质" → AI 自动建流程跑完写报告 |

### 部署形态

- **桌面单机**（首选）：Windows / macOS 双击装，无需联网（除了首次激活）
- **公司 SaaS / 私有化**（可选）：内网服务器，团队共用，2026 H2 后支持
- **公网 SaaS**（`tinia-saas.bestfunc.com`）：个人开发者 + 早期客户测试

### 定价模式

- **按 seat 订阅**（首选）：年付，订阅期内享受节点商店全量更新 + 客服 + 升级
- **永久买断**：一次性付费 + 1 年免费更新，之后按年付维护费续更新

具体定价金额由销售团队提供（视客户规模、商务条件浮动）。

### 跟 HEAD ArtemiS / Siemens Testlab 比

详见 `06-competitive-landscape.md`。简短版：

- **价格**：Pro 单 seat 显著低于传统大厂
- **更新频率**：传统大厂年度发版；Tinia 节点商店即时新增 / 修复
- **AI 协作**：传统大厂没有，Tinia 是原生
- **学习曲线**：传统大厂教程视频多 + 培训贵；Tinia 学习曲线由 AI 接管

## Production —— 在线产线层（2027 规划）

### 目标用户

- **现有 SmartQuality 客户的升级**：从 NG 检测 → NVH 在线监测
- **风电场远程 CMS**（Cloud + Edge）
- **工业泵 / 电机厂 PdM 联合解决方案**

### 提供什么（Production 独占）

| 能力 | 说明 |
|---|---|
| **实时流处理** | 秒级延迟，传感器流式数据进 DAG 实时跑 |
| **多机协同** | 一条产线 5-20 个工位同时跑分析 |
| **数据库 / MES 集成** | 分析结果直接进 ERP / MES 系统 |
| **告警 + 仪表盘** | 异常超阈值实时推送（邮件 / 短信 / Webhook）|
| **模型 OTA** | 流程跨机器全局热更新 |
| **离线 / 在线双模式** | 同一个流程定义，离线分析跟在线流处理用同一份 |

### 部署形态

- **现场边缘节点**：工业级硬件，跑 Tinia engine 实时处理
- **云端协调**：流程定义 / 模型版本 / 历史归档在云端
- **混合架构**：分析跑边缘、模型训练跑云、报告聚合跑云

### 定价

- 按项目（含咨询服务、定制集成）
- 单项目跨度从中小型部署到大型整厂监测都覆盖

### 跟 Tinia Pro 的关系

- 架构上 `tinia-engine` 跟 `tinia-runtime` 的分离就是为 Production 准备的
- Pro 用户可以"零迁移"升级到 Production —— 同一份流程定义、同一个节点生态
- Production 客户也能用 Pro 桌面版做离线分析、调参，调好后部署到产线

## 三层之间的升级路径

```
   研究生写课题       工作几年成为 NVH 工程师       公司部署产线监测
        ↓                       ↓                        ↓
   Community             Pro 试用 → 付费 Pro          Tinia Production
   （免费）               （订阅 / 买断）              （项目制 + 服务）
        ↓                       ↑
   节点商店发布算法 ─────────────┘
   （获得分成 + 简历加分）
```

**关键设计**：

- **数据可携带**：Community 用的流程 / 数据源 / 凭据，升级 Pro 后无缝继承
- **节点向上兼容**：Community 装的免费节点在 Pro / Production 直接可用
- **学生 → 工程师**：通过 Community 培养的用户，工作后会向公司推荐 Pro
- **研究算法商品化**：研究者把课题成果发布到节点商店，反哺 Pro 生态

## 客户问"我该买哪个？"

| 客户描述 | 推荐 | 理由 |
|---|---|---|
| "我是研究生做声学课题" | Community | 免费够用；想发表创新算法可以试节点商店 |
| "我们公司 3 个 NVH 工程师" | Pro × 3 seat | 报告 + 多通道是刚需 |
| "我们想给整车厂出标准测试报告" | Pro 团队版（私有化部署）| 流程模板复用 + 团队共享 |
| "我们风电场 30 个机组，想做 PdM" | Production（2027 启动 PoC，现在用 SmartQuality 过渡）| 等 Production 上线 |
| "我们是大学教授，想给学生开课" | Community + 教育许可 | 教学场景免费，部分节点商店内容可申请教育折扣 |
| "我们做实验室检测服务" | Pro × N seat（按检测工位数）| 报告导出 + 多客户流程模板 |

更多场景判断 → `scenarios/`、`05-target-customers.md`。
