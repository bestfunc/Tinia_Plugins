# 产品矩阵对比

> 一张表看清 Community / Pro / Server / SaaS / Production 五个 SKU 的差异。给客户做评估、给销售判断推荐时直接引用此页。

---

## 速览：5 个 SKU

| SKU | 形态 | 用户 | 状态 | 一句话定位 |
|---|---|---|---|---|
| **Community** | 桌面单机（免费版）| 个人 | ✅ 已交付 | 入门 + 生态层，反向培养未来用户 |
| **Pro** | 桌面单机（付费版）| 个人工程师 | ✅ 已交付 | 个人工程师的完整工作站 |
| **Server** | 私有化 web（付费）| 团队 / 组织 | ✅ 已交付 | 公司内网部署，团队协作 |
| **SaaS** | 公网托管 web（付费）| 团队 / 组织 | 🔜 规划中 | 多组织云端版，0 部署 |
| **Production** | 边缘+云（项目制）| 工厂 | 🔜 规划中（2027）| 在线产线监测 |

**当前商业化阶段（2026 H2 首发）**：Community + Pro + Server 三个 SKU 已可交付。SaaS / Production 在路线图，后期推出。

## Community —— 反向培养生态（已交付）

### 目标用户

- **学生**：本科 / 研究生 / 博士，做声学相关课题
- **研究者**：高校老师、研究院青年研究员
- **个人工程师**：业余研究、Side project、开源贡献者

### 提供什么

| 模块 | Community 提供 |
|---|---|
| 安装 | 桌面单机版，Windows / macOS 直接下载 |
| 基础节点 | 声级表 / FFT / 频谱 / 滤波 / 时域统计等核心算法 |
| 数据源 | 本地文件（wav / mat / unv 等）+ 内置信号发生器 |
| AI 编排 | 完整 MCP 接入，可用 Claude Code / Codex / Qwen CLI 驱动 |
| 节点开发 | 完整 DevStudio + CLI，能写新节点（自用 + 发布到商店）|
| 商店 | 浏览 / 安装免费节点；商业节点单独购买 |

### 限制（保留 Pro 价值，规划中）

| 维度 | Community 限制（规划）|
|---|---|
| 流程复杂度 | 单流程节点数 ≤ 20 |
| 通道 | 单通道分析（多通道节点跑会提示升级 Pro）|
| 报告导出 | 仅截图 + JSON / CSV，不含 PDF / Word / PPT 模板 |
| Order Tracking | 不可用 |

> ⚠ 注：节点级 / 流程复杂度级限制为商业化路线图实现，当前 desktop edition 在未激活时通过激活校验中间件 (`EnforceDesktopActivation`) 受限。详细落地计划见 `commercialization-todo.md`。

### 为什么免费

- **建立生态**：研究者发布算法到商店 → Pro / Server 用户订阅 → 形成正反馈
- **反向培养未来付费用户**：今天的学生是 3 年后的 NVH 工程师
- **传统对手不敢做**：HEAD / Testlab 核心客户是大企业，免费版会侵蚀付费版

### 升级路径

Community 用户用一段时间后碰到限制（节点数 / 通道 / 报告需求），UI 提示"升级 Pro 试用 3 个月"。Pro 试用到期自动降回 Community（保留全部数据 / 流程，仅锁定 Pro 节点）。

## Pro —— 个人工作站（已交付）

### 目标用户

- **整车厂 NVH 工程师**：日常做发动机声品质、风噪、底盘振动等分析
- **独立 NVH 咨询顾问**：跨客户出差、灵活授权
- **自由职业工程师 / 个人专家**：单兵作战不需要团队功能

### 提供什么（Pro 独占，相对 Community）

| 能力 | 说明 |
|---|---|
| **完整节点库** | 全部官方节点 + 节点商店付费节点 |
| **多通道分析** | 麦克风阵列、多传感器同步分析；通道命名模板、Composite DataSource |
| **Order Tracking** | RPM 通道 + 角度域重采样 + Campbell / Order Spectrum / Order Tracker |
| **物理量 + 单位系统** | Pa / g / m/s 全链路贯通，calibration 链路完整 |
| **报告导出** | PDF / Word / PPT，4 个内置模板，可定制 |
| **多运行 overlay** | 多次实验结果叠图对比 |
| **AI 高级编排** | "帮我分析这段录音的声品质" → AI 自动建流程跑完写报告 |

### 部署形态

**桌面单机**（Windows / macOS）。安装包双击装即用，离线可用（除首次激活外）。

### 定价模式

- **按 seat 订阅**（首选）：年付
- **永久买断**：一次性 + 1 年免费更新

单 seat 默认绑 3 台设备（个人 PC + 笔记本 + 公司机），由商店端管理。

## Server —— 团队私有化（已交付）

### 目标用户

- **公司 NVH 团队**：3-30 人，需要共享流程 / 凭据 / 数据源
- **Tier1 测试部门**：项目模板化交付，多工程师协作
- **第三方检测中心 / 测试实验室**：多客户工位共用
- **合资 OEM / 国企 / 央企**：合规 / 内网部署刚需
- **军工 / 医疗 / 航天**：高安全敏感行业

### 跟 Pro 的差异

> 用户经常问"Pro 跟 Server 啥区别"。简短回答：**Pro 是个人，Server 是团队。功能内核一样，差异在协作能力**。

| 维度 | Pro | Server |
|---|---|---|
| **典型用户数** | 1 人 | 3-30 人（小团队）/ 30+（大团队）|
| **形态** | 桌面 app | Web 服务（浏览器访问）|
| **部署** | 工程师本机 | 公司内网服务器 |
| **流程** | 私有，本机 | 团队共享 / 私有可选 |
| **凭据** | 本机加密 | 组织级共享 + 个人级 |
| **数据源** | 本机 | 组织级共享 + 个人级 |
| **用户管理** | 单用户，无需管理 | ✅ 用户 CRUD / 角色 / 权限 |
| **组织设置** | N/A | ✅ 组织名称 / Logo / 默认配置 |
| **报告模板** | 本机模板 | 组织级模板库 + 个人模板 |
| **审计日志** | 本机 | 组织级审计 |
| **数据存储** | 本机 PostgreSQL（嵌入式）| 外部 PostgreSQL（自有 IT 维护）|
| **blob 存储** | 本机文件 | MinIO / S3（外部对象存储）|

**算法 / 节点能力 Pro 跟 Server 完全一样**。

### 部署形态

- **Docker Compose 单机**：中小团队，单 Linux 服务器
- **K8s 部署**：大团队 / 已有 K8s 平台
- **空气隔离环境**：军工 / 涉密客户，完全断网

需要客户 IT 团队参与（准备服务器、PostgreSQL、MinIO），通常 1-2 天可完成（含我方远程协助）。

### 提供什么（Server 独占，相对 Pro）

| 能力 | 说明 |
|---|---|
| **多用户管理** | 用户 CRUD + 角色权限（admin / 普通用户 / 只读）|
| **组织设置** | 组织名称 / Logo / 默认凭据 / 默认数据源 |
| **流程模板库** | 团队 SOP 沉淀，新人开箱即用 |
| **凭据共享** | 组织级凭据（如 Diffgram 账号），权限可控 |
| **数据源共享** | 多人共用数据源 |
| **报告模板组织级** | 主机厂 / 客户模板按组织维护 |
| **审计日志** | 谁改了什么流程、谁跑了什么 |
| **私有化部署文档** | 完整部署 SOP + 远程协助 + 培训 |

### 部署形态

**私有化** — 客户内网部署，Web 服务。

### 定价模式

- 按团队规模 + seat 数订阅 / 买断
- 含部署服务 + 培训 + 优先支持 SLA
- 私有化部署一次性费用 + 后续维护费

## SaaS —— 多组织云端（规划中）

### 目标用户（规划）

- **个人 / 小团队**：免运维、零部署、按需付费
- **跨公司协作场景**：多组织共享流程模板 / 数据源
- **早期试用客户**：注册即用，无需采购流程

### 提供什么（规划）

跟 Server 类似能力，区别在：

- 部署在公网（如 `tinia-saas.bestfunc.com`），用户注册账号即用
- 支持多组织（一个 Tinia 实例托管多个 Org）
- 按 seat 订阅，月付 / 年付灵活

### 当前状态

代码层面 `EditionSaas` 已支持，但**对外正式商业化版本规划中**。当前 SaaS 模式可用作内部测试、早期客户预览。

---

## Production —— 在线产线（规划中，2027）

### 目标用户

- **现有 SmartQuality 客户的升级**（NG 检测 → NVH 在线监测）
- **风电场远程 CMS**（Cloud + Edge）
- **工业泵 / 电机厂 PdM 联合解决方案**

### 提供什么（规划）

| 能力 | 说明 |
|---|---|
| **实时流处理** | 秒级延迟，传感器流式数据进 DAG 实时跑 |
| **多机协同** | 一条产线 5-20 个工位同时跑分析 |
| **数据库 / MES 集成** | 分析结果直接进 ERP / MES 系统 |
| **告警 + 仪表盘** | 异常超阈值实时推送（邮件 / 短信 / Webhook）|
| **模型 OTA** | 流程跨机器全局热更新 |
| **离线 / 在线双模式** | 同一份流程定义，离线分析跟在线流处理用同一份 |

### 部署形态

- 现场边缘节点 + 云端协调
- 跟 Server / Pro 同源节点生态，"零迁移"升级路径

### 定价

按项目（含咨询服务、定制集成、培训）。

## 升级路径

```
                 ↗ Pro（个人付费）↗
   Community ──┤                  ├─ Production（工厂在线，2027）
                 ↘ Server（团队付费） ↘
                          ↓
                      SaaS（规划）
```

**关键设计**：

- **数据可携带**：Community 用的流程 / 数据源 / 凭据，升级 Pro / Server 后无缝继承
- **节点向上兼容**：所有 SKU 用同一个节点生态
- **学生 → 工程师**：通过 Community 培养的用户，工作后会向公司推荐 Pro / Server
- **研究算法商品化**：研究者把课题成果发布到节点商店，反哺所有付费 SKU 生态
- **Pro → Server**：个人工程师晋升管理岗 / 公司组建团队时，从 Pro 个人迁到 Server 团队

## 客户问"我该买哪个？"

| 客户描述 | 推荐 | 理由 |
|---|---|---|
| "我是研究生做声学课题" | Community | 免费够用；想发表创新算法可以试节点商店 |
| "我是 NVH 工程师，自己用" | Pro 单 seat | 个人桌面单机够 |
| "我是独立 NVH 咨询顾问" | Pro 单 seat | 跨客户灵活 + 离线可用 |
| "我们公司 NVH 部门 3-5 人，要团队协作" | **Server**（团队私有化）| 团队管理 + 流程共享 + 内网安全 |
| "我们 NVH 工程师各自独立工作，但要标准化模板" | Server 或 Pro 多 seat（视协作强度）| 协作需求强用 Server，弱用 Pro 多 seat |
| "我们是 Tier1 测试部门 / 检测中心" | Server（多 seat）| 模板库 + 团队协作 + 报告标准化 |
| "我们想给整车厂出标准测试报告" | Server | 主机厂模板按组织维护 |
| "我们公司合规要求数据不出域" | Server（私有化）| 数据 100% 内网 |
| "我们风电场 30 个机组要做 PdM" | Production（2027 启动 PoC，现在用 SmartQuality 过渡）| 等 Production 上线 |
| "我们是大学教授，想给学生开课" | Community + 教育许可 | 教学场景免费，部分节点商店内容可申请教育折扣 |
| "我个人尝试 + 学习" | Community | 免费，限制对个人无影响 |
| "想要 0 部署 + 注册即用" | SaaS（规划中，可联系销售加入早期内测）| 当前还没有 |

更多场景判断 → `scenarios/`、`05-target-customers.md`。
