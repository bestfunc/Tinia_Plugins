## 1. 整车厂 NVH 工程师

### 画像

- **背景**：本科 / 研究生学过振动学 / 信号处理，工作 3-15 年
- **公司类型**：自主品牌车企、合资车企、新能源车企
- **岗位**：发动机 NVH / 电驱 NVH / 整车声品质 / 风噪 / 底盘振动
- **使用工具**：现在用 HEAD ArtemiS / Siemens Testlab / 自己写的 MATLAB 脚本
- **痛点**：
  - HEAD 一个 seat 加模块下来要 6 位数，预算难批
  - 想做新算法（如某个最新论文里的指标）只能等下个版本
  - 老板要日报 / 周报，每次手工搭流程出图 1-2 小时
  - 跟同事协作主要靠传文件，没有"团队流程"概念
  - 新人上手要 3-6 个月培训

### Tinia 怎么帮

- **节点商店即时更新**：研究者发了新算法节点立即就能装上用，不用等大厂下个版本
- **AI 编排**：跟 Claude Code 说"帮我看这段录音的频谱在 RPM 1000-3000 的演化"，AI 自动搭流程 → 输出
- **报告模板复用**：把"日报模板"做成一个流程，每次只换数据源
- **新人友好**：AI 当工程师助手，新人前 2 周也能产出
- **多通道架构**：麦克风阵列分析 / 通道命名模板原生支持

### 推荐 edition

**Pro**（单 seat 订阅）。预算够的话买 3-5 seat 给团队共用。

### 客户决策路径

1. 同行（其他车企朋友 / 论坛）听说 → 下载 Community 试用
2. 用 1-2 周觉得 AI 编排真的省时间 → 申请 Pro 试用 3 个月
3. 试用期内做 1-2 个标杆项目证明价值 → 申请采购预算
4. 公司流程走完（半年-1 年）→ 签 N 个 seat 合同

### 销售要点

- 不要一上来对比"你们功能比 HEAD 少"——HEAD 30 年累积 134 项笛卡尔积算法清单，短期追不上
- 要讲"Tinia 是 AI 工程师助手 + 节点商店"，这是工作方式的代际差异
- 给具体场景：他们日常做的事，用 Tinia 时间缩短到 1/5

## 2. 整车厂 NVH 团队负责人

### 画像

- **背景**：资深 NVH 工程师，工作 10-20 年，带 5-30 人团队
- **决策权**：能批 ¥50-500k 预算的工具采购
- **痛点**：
  - 团队成员各做各的，流程不能复用 → 重复劳动
  - 新人培养成本高 → 老人累、新人慢
  - 标准化报告难推 → 每个工程师有自己的"画图风格"
  - 报告交付时间长 → 项目节点延误
  - 数据安全：HEAD 是单机，敏感数据放本地易丢

### Tinia 怎么帮

- **团队流程库**：把团队 SOP 沉淀为流程模板，新人开箱即用
- **报告模板统一**：组织级模板，所有人输出格式一致
- **集中权限管理**：组织 / 凭据 / 数据源按权限分配，符合内部合规
- **私有化部署可选**：敏感数据不出公司服务器
- **AI 加速**：复杂分析时间从工程师角度从天级到小时级

### 推荐 edition

**Server（团队私有化）**（多 seat） + 可选私有化部署（如果对数据出域有顾虑）。

### 销售要点

- 强调"团队效率 + 标准化"，不是"个人工具升级"
- 给 ROI：N 个工程师 × 工作时间节省 = 年化节省工时
- 私有化部署是关键卖点（合资车企特别敏感）

## 3. Tier1 NVH 测试部门

### 画像

- **公司类型**：汽车 Tier1 供应商（动力总成、底盘、座椅、内饰、电子等）
- **岗位**：NVH 测试工程师 / 主管
- **业务模式**：给主机厂供货前需要出 NVH 测试报告
- **痛点**：
  - 主机厂模板各家不一样，得维护 N 套报告模板
  - 报告交付周期短（有时几天内）
  - 主机厂在线问"为什么这个指标偏高" → 要回头复现分析
  - 流程没沉淀，老工程师离职后新人重做

### Tinia 怎么帮

- **主机厂模板库**：每个客户一套报告模板 + 流程
- **流程版本化**：每次报告对应一个 GraphRun 快照，主机厂质疑时回放
- **AI 解读**：报告自动写"为什么这个指标偏高 + 推荐改进"
- **审计追溯**：版本快照机制保证报告可复现

### 推荐 edition

**Server（团队私有化）**。优先公网 SaaS（多客户便于分享）；如果主机厂要求私有化则改私有化。

### 销售要点

- "你们每个工程师每月节省 N 小时报告时间 = ¥X 折算价值"
- 给 Demo：用一份真实测试数据，30 分钟出完整报告（对比传统 1-2 天）

## 4. 第三方检测中心 / 测试实验室

### 画像

- **公司类型**：CNAS 认证检测中心、汽车 / 风电 / 家电 / 轨道交通声学检测实验室
- **业务**：接客户委托做声学 / 振动测试，出报告收费
- **痛点**：
  - 客户多 + 测试种类多 → 流程零散
  - 报告品牌一致性差 → 影响专业形象
  - 标准方法更新（GB / ISO / SAE）要重新培训
  - 新加测试服务上线慢

### Tinia 怎么帮

- **多客户流程隔离**：每个客户一组 Org，凭据 / 流程 / 报告分离
- **报告品牌定制**：含 logo、CNAS 章、签字栏的定制模板
- **标准节点订阅**：GB / ISO 标准方法节点直接从商店订阅，标准更新即时同步
- **新业务上线快**：从节点商店找现成算法 / 自己写

### 推荐 edition

**Pro 多 seat**（每个测试工位一个 seat）。年订阅模式，跟检测中心的客户合同生命周期匹配。

### 销售要点

- 强调"扩品类的边际成本"：HEAD 加新算法等版本，Tinia 即时从商店装
- 给典型客户故事："某检测中心 Q3 新接了新能源电驱测试业务，用 Tinia 2 周就上线新流程"

## 5. 高校 NVH 实验室 / 研究院

### 画像

- **类型**：985/211 高校的振动 / 声学 / 机械学院实验室、中科院 / 工程院相关研究所
- **岗位**：教授 / 副教授 / 博士后
- **业务**：教学（带研究生）+ 科研（发论文 / 接横向项目）
- **痛点**：
  - 学生写 MATLAB 散乱代码，毕业带走，知识不沉淀
  - 给本科生上课没有合适的"完整工具"
  - 研究成果论文发了之后没人继续用 → 影响力低
  - 给企业做横向项目时工具不专业

### Tinia 怎么帮

- **教学**：Community 免费给学生用，作业 / 实验沉淀为流程模板
- **科研**：研究成果做成节点发布到商店，全行业可订阅 → 影响力 + 收益
- **横向项目**：用 Pro 出专业报告给企业客户
- **传承**：学生流程留在实验室 Org 里，新生入学直接 import

### 推荐 edition

- 教学：**Community + 教育许可计划**
- 科研：**节点商店发布**（学术贡献者激励）
- 横向：**Pro 单 seat**（按需）

### 销售要点

- 不要硬卖 Pro，让实验室自己长起来
- 重点宣传"研究算法商业化"路径 → 教授学术影响力 + 实验室创收
- 提供"教育许可"折扣 + 给教师培训

### 商业逻辑

- 学生毕业去车企当 NVH 工程师 → 自然推荐 Pro
- 研究成果在商店流通 → 反哺 Pro 用户的能力 → 巩固 Pro 价值
- 高校 NVH 实验室是天然的节点贡献者（2027 节点商店生态规划核心来源之一）

## 6. 研究生 / 博士生

### 画像

- **背景**：本科机械 / 物理 / 数学，研究生选了振动 / 声学方向
- **业务**：导师课题 + 自己毕业论文
- **痛点**：
  - 没经费买专业软件
  - 自己写 Python 代码乱、不能复用、容易出 bug
  - 论文 reviewer 要看复现实验，每次找代码翻天覆地
  - 找工作时简历上"用过 Python / MATLAB" 不专业

### Tinia 怎么帮

- **免费**：Community 满足绝大部分课题需求
- **AI 辅助**：跟 Claude Code 写新节点比从零写 Python 快 N 倍
- **流程化**：实验流程可保存、可分享给 reviewer
- **简历加分**："发布过 N 个 Tinia 节点"是真实工程能力证明

### 推荐 edition

**Community**。

### 销售要点

- 不直接销售，靠学术圈 / 知乎 / B 站口碑传播
- 跟有影响力的导师 / 研究生达人合作做 demo 视频
- 学生用着用着碰到 Community 限制（多通道 / Order Tracking）→ 申请 Pro 试用 → 论文写完毕业了反向带去工作单位

## 7. 独立 NVH 咨询顾问

### 画像

- **背景**：HEAD / Testlab 大牛 10-20 年经验，自己出来做咨询
- **业务**：给中小车企 / Tier2 做 NVH 咨询、培训、临时项目
- **痛点**：
  - HEAD 单机许可贵且只能装一台机器 → 出差到客户现场不能用
  - 客户多 / 项目多，流程混
  - 想把"老师傅经验"产品化但没载体

### Tinia 怎么帮

- **灵活授权**：Pro 单 seat 订阅，跨机器（按 device fingerprint 限定数量）
- **流程库**：积累 N 个客户的"通用诊断流程"，下次重用
- **商业节点发布**：把"老师傅经验"做成商业节点放商店，被动收益

### 推荐 edition

**Pro 单 seat（订阅）** + 鼓励发布商业节点。

### 销售要点

- 单价不高 + 灵活订阅吸引这类自由职业者
- 强调"商业节点 30% 分成是被动收入" → 资深顾问的退休金
- 给"早期开发者扶持计划"

## 8. 工厂 / 设备厂 PdM 团队

### 画像

- **公司类型**：风电场运维方、工业泵厂、电机厂、燃气轮机厂
- **岗位**：设备健康监测工程师 / PdM 项目经理
- **业务**：在产线 / 设备上装传感器，做异常检测 + 预测性维护
- **痛点**：
  - 现有工具是"震动监测 + 简单阈值告警"，不智能
  - 想用心声 / 复杂指标 → 没有合适在线工具
  - 业务方要看仪表盘、模型要 OTA、MES 要集成 → 现有工具做不了

### Tinia 怎么帮

- **2026 H2**：用 SmartQuality 现有产品（Bestfunc 在线检测平台）过渡
- **2027 启动 Tinia Production**：
  - 实时流处理，秒级延迟
  - 多机协同（一条产线多工位）
  - MES 集成
  - 模型 OTA + 流程热更新

### 推荐 edition

**Production**（2027）。当前阶段先用 SmartQuality + Tinia Pro 做离线分析调参。

### 销售要点

- 这是 2027 主线，2026 不卖
- 当前阶段在客户那做 PoC，预热
