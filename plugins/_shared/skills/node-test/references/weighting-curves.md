## 测试方案（chirp 法）

```
signal_generator (chirp, 20-20000 Hz, log, duration=10s, sr=192000, amp=0.5)
  ↓
weighting_filter (weighting=A)
  ↓
fft_spectrum (n_fft=16384, window=hann, scale=linear, ref_pressure=1.0)
  ↓
spectrum_viewer
```

**判定**：在 spectrum 中读出每个标准频点的幅度，与表中 A 列对比。
- 容差：见下面的 sample_rate 影响表
- 1 kHz 处必须为 0 dB（归一化锚点，误差 < 0.01 dB）

## sample_rate 对计权精度的影响

双线性变换在 Nyquist 附近（>= sr/4）会产生频率压缩误差。这是数学固有特性，不是 bug。

| sr (Hz) | 1 kHz 处误差 | 4 kHz 处误差 | 8 kHz 处误差 | 16 kHz 处误差 | IEC Class |
|--------:|-------------:|-------------:|-------------:|--------------:|:---------:|
| 16000   | < 0.05 dB    | < 0.5 dB     | -            | -             | < 8 kHz |
| 22050   | < 0.05 dB    | < 0.3 dB     | -1 ~ -3 dB   | -             | -       |
| 44100   | < 0.05 dB    | < 0.1 dB     | < 0.3 dB     | -3 ~ -6 dB    | Class 2 |
| 48000   | < 0.05 dB    | < 0.1 dB     | < 0.2 dB     | -2 ~ -5 dB    | Class 1*|
| 96000   | < 0.01 dB    | < 0.05 dB    | < 0.1 dB     | < 0.5 dB      | Class 1 |
| 192000  | < 0.01 dB    | < 0.02 dB    | < 0.05 dB    | < 0.1 dB      | Class 0 |

\* sr=48000 在 16 kHz 处达不到 Class 1 的 ±1.5 dB，但 8 kHz 以下满足。

**测试时给的容差应该按 sr 选**：sr=48k 测 16 kHz 不能要求 ±0.5 dB。

## 验证锚点（必看）

无论 sr 多少，这几个锚点必须满足，否则节点本身有 bug：

| 频点 | 期望 (A) | 期望 (C) | 容差 |
|-----:|---------:|---------:|-----:|
| 1 kHz | 0.0 dB | 0.0 dB | < 0.05 dB |
| 500 Hz | -3.2 dB | 0.0 dB | < 0.3 dB |
| 100 Hz | -19.1 dB | -0.3 dB | < 0.5 dB |
| 4 kHz | +1.0 dB | -0.8 dB | < 0.5 dB |

如果这几个点偏离 > 1 dB，问题不在 sr，而是计权传函系数错或归一化没做。

## 与 octave_analysis weighting 的差别

`octave_analysis` 的 weighting 是**对每个倍频程频带的中心频率值查表 + 加在 dB 上**，不是真把信号过计权滤波器。所以：

- 测 octave 的 A 计权：给宽带白噪声（所有频带都有能量），看带 A 的 LAeq 比 Z 低
- 测精度：用 1 kHz sine（应只在 1k 频带有能量），A 和 Z 应都接近 -94 + 20*log10(amp/2/2e-5)
- octave 的 A/C 误差比 weighting_filter 小（直接查表），sr 影响很小

## fft_spectrum scale=dBA 怎么验证

`fft_spectrum scale=dBA` 是在算完线性频谱后**逐频点查 A 计权值并相加**。

```
signal_generator (sine, 100 Hz, amp=0.5, sr=48000)
  ↓
fft_spectrum (scale=dBA, ref_pressure=1.0)
  ↓
spectrum_viewer  ← 100 Hz 处幅度 ≈ 满量程对应 dB - 19.1
```

具体说：100 Hz 的 sine amp=0.5 → linear 幅度 0.25 → dBFS 约 -12 → dBA 约 -12 + (-19.1) = -31.1 dB

## 常见错误

1. **混淆"信号经计权滤波后"vs"频谱叠加计权值"** — 前者是时域操作（weighting_filter），后者是显示加权（fft_spectrum scale=dBA）。结果接近但不严格相等（计权滤波是因果 IIR，会有相位延迟）。

2. **测 weighting_filter 用 chirp 看到曲线"漂"** — 多半是 `output_dtype=float32` 在 16 kHz 附近 quantization 噪声。换 float64 看是否好转。

3. **dB scale 加上 ref_pressure=1.0 时基准变了** — fft_spectrum 的 dB 是 20*log10(|X|/ref)，ref=20u (Pa) 才是真正 SPL。归一化信号测计权曲线建议用 ref_pressure=1.0 + scale=linear，避免 ref 影响。
